# @studely/types

Types TypeScript partagés entre `apps/api` et `apps/front`.

Contient pour l'instant uniquement des types transverses génériques (enveloppe
d'erreur API, pagination). Les types de domaine (Centre, Course, FamilleFormation,
Article, ...) seront ajoutés au fil des tickets qui modélisent ces entités
(ST-11 côté Directus, puis leur consommation front en ST-12) plutôt
qu'anticipés ici.
